    DNP3 Link Layer CRC-16: Polynomial 0x3D65 | Initial Seed 0x0000 | Final XOR 0xFFFF | Inverted & Little-Endian

    CRC algorithm details
    • Name: CRC-16/DNP (reflected: input and output bits reversed, LSB first).
    • Polynomial 0x3D65 = x16 + x13 + x12 + x11 + x10 + x8 + x6 + x5 + x2 + 1. Reflected form for shift-right code: 0xA6BC.
    • Seed 0x0000. Final XOR 0xFFFF (the result is inverted).
    • Sent low byte first. One CRC covers the 8 header bytes, then each data block of up to 16 bytes has its own.
    • Check value: CRC of ASCII "123456789" = 0xEA82.
    • Frame test: 05 64 05 C0 01 00 00 04 gives CRC 0x21E9, sent as E9 21.
